# Sistema de Rastreamento

Projeto desenvolvido para monitoramento e rastreamento.

## Objetivo

Desenvolver um sistema capaz de acompanhar a localização de um objeto
ou dispositivo e apresentar essas informações ao usuário.

## Tecnologias

- HTML
- CSS
- JavaScript
- Python
- Banco de dados

## Funcionalidades

- Cadastro de dispositivos
- Rastreamento
- Visualização da localização
- Histórico de posições
- Atualização da localização
